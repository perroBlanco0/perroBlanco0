## 👋 Hi, I'm Byron

**Full Stack Developer** from Santiago, Chile. I build end-to-end products: APIs in **Python/FastAPI**, interfaces in **React**, mobile apps with **Capacitor**, and containerized deployments on the cloud. Lately I spend most of my time building **AI agents** and shipping them at **hackathons**.

- 🤖 I build AI agents that act, verify and correct themselves, not just chat.
- 🧠 Founder of **[Symbolic Engine](https://symbolicengine.tech)**: deterministic symbolic verification with hyperdimensional computing, with no GPU.
- 🛠️ I ship tools people use, like **LLM Context Builder** on the Visual Studio Marketplace.
- ☁️ I design cloud architectures on **AWS** (load balancing, auto scaling, monitoring, messaging).
- 📊 I build data pipelines from SQL Server and AWS to **Power BI** dashboards.
